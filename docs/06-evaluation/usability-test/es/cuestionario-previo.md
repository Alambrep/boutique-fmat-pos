# Cuestionario previo

> Lo llena el facilitador con las respuestas del participante. Revisa los criterios de reclutamiento del [protocolo §3](../protocol.md#3-participants-4b). Código del participante: `PRX-__`

| # | Pregunta | Respuesta | Criterio |
|---|---|---|---|
| 1 | ¿Trabajas o estudias algo relacionado con informática, software o sistemas? | Sí / No | Grupos A y B: debe ser **No** |
| 2 | ¿Para qué usas normalmente tu celular? (marca todas las que apliquen) | Llamadas · Mensajes · Redes sociales · Banco · Apps de trabajo · Otra: ____ | Grupo A: principalmente llamadas, mensajes y redes sociales |
| 3 | ¿Has usado alguna app o máquina para cobrar o registrar ventas? ¿Cuál? | Sí / No · ____ | Grupo A: debe ser **No** |
| 4 | En tu trabajo, ¿llenas formularios o usas hojas de cálculo (por ejemplo, Excel) sin ayuda? | Sí / No | Grupo B: debe ser **Sí** |
| 5 | ¿Qué celular usas? | Android / iPhone / Otro · Modelo (si lo sabe): ____ | Solo para describir a los participantes |
| 6 | ¿Con qué mano sueles usar el celular? | Derecha / Izquierda / Las dos | Solo para describir a los participantes |

**Resultado:** cumple los criterios del grupo A / grupo B / no cumple (se agradece y no se hace la prueba).
