# Instrument — Observation guide (V-01)

> Contextual inquiry at the points of sale. Administered in Spanish; this is the reference version. Hypotheses: H-01, H-03, H-05, H-06, H-09.

## Before starting (consent script)
"I am a Software Engineering student at FMAT working on a project to improve the boutique's sales and inventory system. I would like to observe how sales are done here for about 30 minutes and ask a few questions. I will not record your name, photos or audio. You can stop at any time. Is that OK?"

- [ ] Consent given (yes/no) · Participant code: `SEL-__` · Point: ______ · Date/time: ______

## What to observe
| # | Observation | Notes | Hypothesis |
|---|---|---|---|
| O1 | What is used to record a sale (notebook, spreadsheet, phone app, nothing)? | | H-04 |
| O2 | Time from the customer asking to the sale being recorded (measure 3–5 sales) | | NFR-04 baseline |
| O3 | Number of items per sale | | H-09 |
| O4 | Queue or waiting customers? At what times? | | H-05 |
| O5 | Interruptions during a sale (phone, other tasks); hands occupied? | | H-06 |
| O6 | Payment methods used; any Interuady sale? How is it recorded? | | H-08, H-14 |
| O7 | How does the seller check stock? | | H-04 |
| O8 | Signs of difficulty with technology (asks for help, avoids the phone, errors) | | H-01 |
| O9 | Connectivity problems observed | | H-03 |

## Questions during observation (ask only when it does not interrupt a sale)
- "Can you tell me what you just did and why?"
- "What happens when you run out of a size or color?"
- "What is the hardest part of recording a sale?"
