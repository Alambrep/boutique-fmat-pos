# Participant-facing field versions (Spanish)

These files are the **Spanish versions used in the field**: what is read aloud or shown to participants. They are an exception to the English-only rule of the repository ([README §11](../../../../README.md#11-language)), because the participants speak Spanish.

| Field version (Spanish) | English reference version | Activity |
|---|---|---|
| [`guia-observacion.md`](guia-observacion.md) | [Observation guide](../observation-guide.md) | V-01 |
| [`guia-entrevista-vendedores.md`](guia-entrevista-vendedores.md) | [Seller interview guide](../seller-interview-guide.md) | V-02 |
| [`guia-entrevista-personal.md`](guia-entrevista-personal.md) | [Staff and client interview guide](../staff-interview-guide.md) | V-03, V-04, V-06 |

The [device and connectivity checklist](../device-connectivity-checklist.md) (V-05) is filled in by the author and is not shown to participants, so it has no Spanish version.

**Rules**

- The English version is the reference: question numbers and hypothesis labels are the same in both, so notes can be analyzed against the English plan.
- If a question changes, both versions change in the same commit.
- Translated by the AI assistant from the English reference versions on 2026-10-27. **Reviewed by the author on 2026-10-31:** interviews may be audio-recorded with explicit consent, to save time for both sides (transcribed afterwards); observation at the boutique stays without any recording, as reserved as possible. The guides keep addressing participants as *usted* (no change requested).
